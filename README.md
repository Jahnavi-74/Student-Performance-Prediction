# Student Performance Prediction using Linear Regression

## Project Overview

This project predicts students' exam scores using the Linear Regression algorithm based on study hours, attendance, previous scores, and sleep hours.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

## Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Feature Selection
- Train-Test Split
- Linear Regression Model
- Model Evaluation
- Prediction of New Student Scores

## Project Workflow

1. Load Dataset
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Train-Test Split
6. Train Linear Regression Model
7. Evaluate Model
8. Predict Student Scores
9. Save Trained Model

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
